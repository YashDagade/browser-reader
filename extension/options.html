A FEW DETAILS

Tempo reads visible article text and skips common navigation, ads, captions, and controls. Page restrictions and unusual layouts can require selecting or pasting text. Chrome’s built-in PDF viewer and internal pages cannot be highlighted.

On-device mode keeps text on your Mac. OpenAI mode sends only the text sections you play and a few upcoming sections to OpenAI through a service on this Mac. The API key stays out of webpages and the extension. Audio uses a bounded memory cache, cleared when the local service exits.

OpenAI voices are AI generated. Word highlighting and seeking use estimated timing with OpenAI audio; the Mac voice uses available word events. Speech generation requires a short initial buffer. Speed changes apply immediately to buffered OpenAI audio.

Chrome installs unpacked extensions separately for each profile. Load the same extension folder in each profile; they share the local OpenAI connection. Reader preferences are separate per profile.
