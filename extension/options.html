OPENAI CONNECTION

Checking your reader…

For your own Chrome profile, Hermes can call OpenAI directly. Your key stays in memory in this Chrome profile until Chrome fully quits. It is never written to disk by Hermes, synced, or exposed to webpages. Re-import it after restarting Chrome. Use your own API key.

Keys are never shown here. Leave empty to keep the key for this browser session.

The file stays on your computer. Hermes reads only OPENAI_API_KEY; no file is uploaded.

The optional local helper keeps your key in a Git-ignored .env.local file. Run npm start, or install the login service once on macOS. The direct option above needs neither Node nor a backend.

This applies to direct and local-helper connections. Only enable it for content you want to share with OpenAI. Privacy policy

START LISTENING
  1. Pin Hermes from Chrome’s extensions menu.
  2. Open an article, then click Hermes to open the player.
  3. Click Start reading. Change the speed as you listen.

Select text before opening Hermes to read just that passage. Double-click a word in the article to jump to it. Open player settings to paste any body of text.

VOICE DEFAULTS

Custom guidance stays in memory until Chrome quits. Applies to the expressive OpenAI voice. Hermes always asks the voice to read your text verbatim. Older OpenAI models and on-device voices do not support prompts.

Improved timing sends generated audio to OpenAI transcription for word timestamps, with a small extra API cost. Reading starts without waiting for alignment.

SAVED AUDIO

Replay buffered passages without generating them again. Speed changes reuse the same audio; changing the voice, model, text, or supported instructions may generate new audio.

Checking saved audio…

Saved audio is encrypted with a key kept only in memory. Replay works across pages during this Chrome session. Quitting Chrome discards the key; old audio is removed on the next cache access. Entries also expire after seven days and older passages are removed when the cache fills. Stop reading before clearing if you want it to stay empty.

A FEW DETAILS

Hermes reads visible article text and skips common navigation, ads, captions, and controls. Page restrictions and unusual layouts can require selecting or pasting text. Chrome’s built-in PDF viewer and internal pages cannot be highlighted.

On-device mode keeps text on your computer. OpenAI mode sends the text sections you play and a few upcoming sections to OpenAI. Improved timing also sends the generated audio to OpenAI. Hermes encrypts generated audio and numeric word timings in this Chrome profile for replay during the current browser session, with a 32 MiB limit and seven-day maximum expiry. Original text, article URLs, and credentials are not stored in the audio cache. The audio itself contains the spoken text. Audio in memory is limited to 12 MiB; decoding and the page use additional memory.

OpenAI voices are AI generated. Word timing uses speech timestamps when available and estimates while waiting or when alignment fails. Speech generation requires a short initial buffer. Speed changes apply immediately to buffered OpenAI audio.

Chrome installs unpacked extensions separately for each profile. Load the same extension folder in each profile. Direct connections and preferences are separate per profile; profiles can share one local helper.
